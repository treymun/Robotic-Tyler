Phone remote

Control Tyler from your phone's browser on the same Wi-Fi. The phone shows Tyler's panel in your theme, live, with the theme's extras: start or pause him, play clips, run the Music DJ, type in chat, change the theme and more. Nothing to install. A paired phone can read the chat's latest 40 messages for its Chat log card (it asks only while the card is open), and can open these Settings to change them. It never sees your API keys (only whether one is saved) and can't add or remove them; pairing phones, installs and tests stay on this PC.

The phone remote is part of the desktop app: it runs a small page on your home network, which a Chrome extension can't do.

    Which model, and what “uncensored” means

    4B and 9B are Alibaba's Qwen3.5 models (Apache-2.0 licence) in a 4-bit file (Q4_K_M) made by Unsloth. The 9B writes better replies and follows the chat better; the 4B is about twice as fast and needs half the memory. Both run with their thinking turned off, so they answer straight away.

    Uncensored versions are huihui-ai's “abliterated” Qwen3.5 (also Apache-2.0), packed by mradermacher: the community removed the model's habit of refusing, so crude banter and hard roasts aren't turned down. That edit makes them a little less accurate. Tyler's own chat rules and the protection against chat takeovers still apply to every model.

    None of these is as capable as the large cloud models: expect shorter, simpler banter. Your personality settings and reply length are used as with any provider.

        Quality or Lightweight?

        Quality uses the larger model (Qwen3-TTS 1.7B). It copies each character's voice more closely and stumbles less (fewer odd pauses or misread words). It needs about 6.5 GB of free graphics memory on an NVIDIA card, or about 6 GB of free memory on the processor. Download: about 4.2 GB for the model.

        Lightweight uses the smaller model (Qwen3-TTS 0.6B). It needs about 4 GB of graphics memory on an NVIDIA card; on the processor it needs about as much memory as Quality. On the processor it's a little faster; on a graphics card the two take about as long. The voices sound a little less like the originals and odd pauses happen more often (Tyler retries a take that comes out the wrong length). Download: about 2.3 GB for the model.

        Both use the same voice engine (about 2.7 GB with graphics-card support, 0.25 GB for the processor only). You can install both and switch any time. With the standard engine, theme voices are made ahead of playing, not live: on a mid-range NVIDIA card a short line takes several seconds.

        Standard or fast engine?

        Standard is Qwen3-TTS's own code. It works on any PC, with or without a graphics card.

        Fast is faster-qwen3-tts (MIT licence): the same Qwen3-TTS models and the same 25 voices, run with CUDA graphs on an NVIDIA card. Its published figures, on an RTX 4060 laptop-class card under Windows, are about 1.8 seconds of speech made per second with Quality and 2.3 with Lightweight (the standard engine: about 0.23), with the first audio ready in under half a second. That's quick enough for Tyler to answer in a theme voice during a call (Settings → Voice → Speaking voice). It's new in Tyler and hasn't been tested on every card yet: Run a voice check after switching shows the real speed on your PC.

        Switching downloads only what's different (about 15 MB); the rest of the engine is reused. You can switch back the same way. It needs the graphics card: with Processor only Tyler uses the standard engine.

        Checking the character voices…

        Sharper character voices (experimental)

        For Medic, Lash and Kelvin, Tyler can also run the generated speech through voice conversion (kNN-VC): each moment of the clone's speech is swapped for the closest-sounding moments of that character's own recordings, which are built into the app. It's off until you switch it on in the character's row above, and it needs a separate download. It was measured, not listened to: closer for Medic, and nearly for Lash and Kelvin (each missed one test on one of two tries). It's slower (about 0.35–0.6 s more per second of speech on a processor), uses about 1.7 GB more memory while it's loaded, and its sound is made at 16 kHz (then resampled to 24 kHz), so it's a little less crisp. If it's on but can't run, the character's normal voice speaks and says why.

        Checking voice conversion…

        Downloaded only when you press the button, from the kNN-VC project's v0.1 release on GitHub, and each file is checked against the SHA-256 recorded in this version of Tyler (a stopped download carries on where it stopped). WavLM-Large is Microsoft's (its model card points to a Creative Commons Attribution-ShareAlike 3.0 licence); the vocoder and kNN-VC's code are MIT-licensed.
