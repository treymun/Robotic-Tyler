Steam chat appearance

Match Steam chat inside this desktop app to Tyler’s selected theme. These controls apply immediately and do not change the theme.

Colors only uses the theme’s palette. Full styling adds textures, tab and button finishes, and matching Tyler artwork in empty chat. Full also hides Steam’s website navigation strip. Open Friends List still opens the Steam list.

Full may temporarily use Colors only if Steam changes its chat page. If chat is hard to read or use, return to this separate Settings window and choose Off or Colors only.
