# Retired: three programs

Before v2.15, ROBOTIC TYLER shipped three programs: the Chrome extension, a text-only Control
Center and a separate Native Steam Companion (Voice Studio). v2.15 merged the two Windows apps
into one desktop app with Steam text chat and Steam voice (Standard or Gemini Live). See the
README and CHANGES.md (2.15.0) for how upgrades and settings imports work.
