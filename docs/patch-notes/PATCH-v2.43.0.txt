# ROBOTIC TYLER v2.43.0: Character voices built in

## New
- **The character voices' recordings come with the desktop app. There's nothing to import.**
  - All 30 characters are built in: TF2's classes, the 13 Deadlock heroes, Wheatley, Cave Johnson, Coach, Ellis, Zoey, the Phoenix, Leet and Alyx.
  - Install theme voices as before (the one-click download of the voice engine and model; unchanged). Then every offered character just works.
  - Pick one in **Settings → Theme voices → Character voices** or on the phone remote, or use `!say tf2/scout TEXT` in chat.
  - **Original recording** plays the game's own line for every character, Pyro included.
- **The 5 improved voices use their version 2 from the start:** Coach, Seven, Zoey, Kelvin and Venator. You no longer need the voice supplement for them.
- You asked: *"i want the user to be able to do it without installing more files to import."*

## Changed
- **The installer is about 15 MB larger.** It now holds the 196 recordings the characters use: every clip of every version, and each one's *Original recording*.
  - They're byte for byte the clips from your two packs, *Robotic-Tyler-Character-Voice-Expansion* and *Robotic-Tyler-Complete-Voice-Supplement*.
  - Nothing else from the packs is included.
- **Settings' status line** now reads *"30 character voices built in (29 offered) for 6 themes."*
  - It no longer says *"Not imported yet"*, and it no longer asks for the voice supplement.
  - Pyro is still not offered: he never passed his voice test. He shows as *not approved*, as before.
- **Import character voices** is still there, but it's optional now.
  - It moved below the character list.
  - Use it only to repair a damaged recording, or to add recordings.
  - A recording that's already here (built in, or imported before) is never copied again. Importing your packs now changes nothing.
- **"Remove imported character voices" is now "Remove imported copies".**
  - It only shows when you have imported copies.
  - It deletes only those. The built-in recordings can't be removed.
- **If you imported the packs in v2.41 or v2.42**, your import keeps working.
  - Its copies are the same recordings that are now built in, so Tyler removes them once each built-in copy checks out (about 15 MB freed). Nothing is kept twice.
  - Your picks and your *Use the earlier version* choices are kept.
- The Chrome extension doesn't change: it has no theme voices.

## How it behaves
- **Each recording is checked before it's used:** its exact size and its SHA-256 must match the catalog.
- **A damaged install never switches silently.**
  - If a built-in recording is missing or damaged, an improved character uses its **earlier version** and says why: *"Earlier version (v1): the improved version (v2) can't be used (one of its built-in recordings is damaged: run the Setup again to repair the app)."*
  - If no version can be used, the **theme's own voice** speaks, with the reason.
  - You see it in Settings (on the character's row and in the status line), on the panel, on the phone and on the clip.
  - **To fix it:** run the Setup again, or import the voice packs.
- **Unchanged:**
  - The theme's own voice stays the default. Each theme remembers its own pick.
  - *Use the earlier version* and *Use the improved version* work as before.
  - Cached clips are keyed by the recordings' content, so they stay valid. Clips you made from an import are still used.
  - An unknown or unapproved character falls back to the theme's voice, with the reason.
  - The phone remote's character list works as before. It now lists every offered character without an import.
- **Where they are:** `app/theme-voices/characters/<theme>/<character>/<sha256>.flac`.
  - In the installed app they sit outside `app.asar` (in `app.asar.unpacked`), like the 25 theme voices' recordings and the voice engine's script.
  - This is because the voice engine is a separate Python program, and it can't read inside `app.asar`. It reads them where they are, so nothing is copied at first use.
