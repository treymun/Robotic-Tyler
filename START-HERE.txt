ROBOTIC TYLER — v2.23.0

JUST WANT TO USE IT?
  Download ROBOTIC-TYLER-Setup-2.23.0.exe from
  github.com/treymun/Robotic-Tyler/releases/latest and run it. Two parts:
    Desktop app        → Steam chat and Steam voice on Windows, no Chrome needed
                         (voice: Standard or Gemini Live, right in its Steam window)
    Chrome extension   → Setup unpacks it and opens Chrome's extensions page;
                         turn on Developer mode, click Load unpacked, paste the path
  Run Setup again later to add or update a part. Settings and keys are kept.
  The desktop app replaces the old Control Center (upgraded in place) and Voice
  Studio (its settings are imported on first start; it then offers to remove it).
  Pick a look in Settings → Appearance: 20 themes, from Steam, Team Fortress 2,
  Counter-Strike 2 and Portal to DOOM, Deadlock, PAYDAY 2 and Day of Defeat.

VOICE ON THE DESKTOP (v2.19):
  1. Sign in to the bot's Steam account in the app's Steam chat window.
  2. Settings: add your AI key; Settings → Voice: pick Standard or Gemini Live.
  3. In Steam chat, open the group, then Tyler's panel → Connect & start (or
     Start live voice), and join the voice channel. No VB-CABLE needed: Tyler
     talks through his own synthetic microphone.
  Prefer the older route through VB-CABLE and the Steam desktop app? Settings →
  Voice → Where Tyler joins voice → "Through VB-CABLE", then set Tyler speaks
  into = CABLE Input, Tyler listens to = your headset, and Steam's microphone =
  CABLE Output, and start voice from the Voice window (Ctrl+Shift+V).

UPDATING CHROME FROM THIS FOLDER:
  Copy browser-extension/ over the same folder you loaded before, then click
  Reload on Tyler's card in chrome://extensions (keeps settings and keys).

EDITING THE CODE:
  Change files in browser-extension/ only, then run
    node tools/build.mjs     (regenerates the desktop copies and ui-template.js)
    npm run test:all         (build check, unit tests, end-to-end tests)
  BUILD-WINDOWS-EXE.cmd builds the desktop installer and Setup on Windows.
  CHANGES.md has every release (newest first); RELEASING.md covers releases,
  installers, auto-updates and code signing. Guides live in docs/.
