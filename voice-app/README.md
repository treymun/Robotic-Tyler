# Voice window (desktop app)

Since v2.15 this folder is the desktop app's **Voice** window (`native.html`, `native.js`,
`native-preload.cjs`); the separate Voice Studio app is retired. The main process is
`app/main.cjs` and the audio work is in `app/native-voice.cjs`, which drives the Windows audio
helper in `windows-audio-bridge/`.

Tyler talks into a virtual cable (VB-CABLE) that the Steam desktop client uses as its microphone
and listens to the one output device you choose (loopback), never a microphone. Standard voice
and Gemini Live both go through the same conversation engine as the Chrome extension. Devices,
consent and the engine are set in Settings → Voice.

`tokens.css`, `themes/`, `fonts/`, `logos/`, `icons.css`, `kit.css`, `ui-icons.js` and
`ui-kit.js` are generated by `tools/build.mjs`.
